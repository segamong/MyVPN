# Приватность MyVPN

MyVPN — клиент для серверов, которые пользователь выбирает сам. В этом форке не добавлены аналитика, рекламные SDK, учётные записи или централизованный сервер MyVPN.

VPN-профили, настройки и адреса подписок хранятся локально в закрытом каталоге приложения средствами исходного клиента v2rayNG. Автоматическое резервное копирование Android отключено. Ручной экспорт и резервные копии могут содержать действующие ключи подключения; их следует хранить приватно.

Сетевые обращения зависят от действий и настроек пользователя:

- Трафик VPN направляется выбранному серверу; его оператор может видеть доступные ему сведения о соединениях.
- Для обновления подписки приложение обращается по указанной пользователем ссылке.
- Проверка задержки, DNS, внешнего IP, геоданных и обновлений использует настроенные адреса и исходные механизмы v2rayNG. Это может включать обращения к GitHub и внешним службам проверки соединения.
- Камера используется для сканирования QR-кодов после системного разрешения. Импорт из буфера обмена выполняется по действию пользователя.
- Выбор приложений для маршрутизации требует доступа к списку установленных приложений. Этот список используется локально.

SSH-доступ и учётные данные администратора 3x-ui не требуются и не входят в приложение или публичный репозиторий. Доступ через VPN не заменяет HTTPS и проверку сертификатов.

Исходный код доступен в [segamong/MyVPN](https://github.com/segamong/MyVPN). Обращения об ошибках — в Issues; не прикладывайте полные VPN-ссылки, UUID, приватные ключи или токены подписок.
