# MyVPN для Android

Персональный VPN-клиент для подключения к своему серверу с 3x-ui / Xray. MyVPN — открытая доработка [v2rayNG 2.3.11](https://github.com/2dust/v2rayNG/tree/2.3.11), с отдельным Android-пакетом `com.segamong.myvpn`, своим главным экраном, иконкой и оформлением. Лицензия GPLv3 и история авторов сохранены.

## Возможности

- Включение и отключение VPN через системную службу Android.
- Профили VLESS / Reality, VMess, Trojan, Shadowsocks и другие протоколы исходного клиента.
- Импорт из буфера обмена, QR-кода, файла и подписки; ручное создание и редактирование профилей.
- Несколько профилей и групп, тест задержки и проверка подключения.
- Маршрутизация, выбор приложений, собственные DNS, IPv6, виджет и плитка быстрых настроек.
- Русский интерфейс, светлая и тёмная темы, системные динамические цвета на Android 12+.

Требуется Android 7.0 или новее. Это самостоятельное приложение: его можно установить рядом с v2rayNG.

## Установка APK

Откройте [Actions → MyVPN Android](https://github.com/segamong/MyVPN/actions/workflows/myvpn-build.yml), выберите успешную сборку текущего `main`, скачайте артефакт APK и распакуйте ZIP. Для большинства современных телефонов нужен `arm64-v8a`; `universal` подходит для всех включённых архитектур. Перенесите APK на телефон и откройте его.

CI выпускает **debug APK для тестирования** без секретов подписи. Это не подписанный постоянным release-ключом выпуск. Отладочная подпись между сборками может меняться; для стабильных обновлений нужен ваш постоянный приватный ключ. Подробности — [сборка](docs/BUILD.md).

## Подключение к вашему серверу

1. В своей панели 3x-ui откройте существующее входящее подключение и клиента.
2. Скопируйте **ссылку подключения клиента** (`vless://…`, `vmess://…`, `trojan://…` и т. п.) либо покажите QR-код. Адрес административной панели не является VPN-профилем.
3. В MyVPN нажмите **Вставить ссылку** либо **Сканировать QR-код**. Для ссылки подписки используйте раздел **Группы подписок**, добавьте URL и обновите подписку.
4. Выберите импортированный профиль и нажмите **Подключить**. Подтвердите стандартный запрос VPN на телефоне.
5. Нажмите значок проверки подключения. Состояние «Служба запущена» показывает состояние локального клиента; доступность сервера проверяется отдельно.

Ручной профиль создаётся через **Добавить → Ввести вручную** либо кнопку **Создать профиль VLESS**. Перенесите точные порт, UUID/пароль, транспорт и TLS/Reality-параметры из 3x-ui. Для Reality особенно важны `serverName` (SNI), публичный ключ, short ID, fingerprint и flow, если он задан сервером.

**Создание профиля на телефоне не создаёт нового клиента в 3x-ui.** Сначала клиент должен существовать на сервере. Приложению не нужны SSH-пароль или пароль администратора панели. По одному IP невозможно определить корректные порт, UUID и ключ Reality; они намеренно не включены в исходный код.

## Что сделано в этом форке

- Новый главный экран MyVPN с карточкой состояния, кнопками подключения и добавления, подсказками для первого профиля.
- Собственная иконка, палитра и имя приложения; удалён рекламный пункт бокового меню.
- Ссылки исходного кода, обратной связи, политики приватности и проверки обновлений ведут в этот репозиторий; источник v2rayNG указан в разделе «О приложении».
- Отключён автоматический Android backup данных приложения, содержащих VPN-профили.
- Отдельная CI-сборка native-зависимостей из зафиксированных git submodule ревизий и APK с отчётами проверок.

## Сборка и проверка

См. [docs/BUILD.md](docs/BUILD.md). VPN-ядро и жизненный цикл службы сохранены из upstream. Готовность конкретного APK определяется зелёной сборкой соответствующего коммита; компиляция сама по себе не подтверждает работу с конкретным сервером. Проверку на реальном Android-телефоне с вашим личным профилем нужно выполнить отдельно.
